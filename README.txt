K2 CLASSES WEBSITE
==================

OPEN IT
  Double-click index.html. It opens in your browser.

WHAT IS INSIDE
  index.html        the page (headings and sections)
  assets/styles.css all colours, layout and animations
  assets/content.js YOUR CONTENT: toppers, teachers, timings, fees, T-shirt, address, phone
  assets/main.js    the code that builds the page (you normally never edit this)
  photos/           topper photos, gallery photos and the T-shirt photo
  k2-classes-single-file.html   the same site as ONE file (everything built in)

HOW TO CHANGE THINGS
  Open assets/content.js in Antigravity or VS Code and change the text.
  To add a topper: copy one line, change the name, class, marks, and put the
  photo in the photos folder with the same file name as written on that line.

HOW TO PUT IT ONLINE
  Upload the WHOLE folder (index.html, assets, photos) to your host.
  - GitHub Pages: put all of it in a public repository, then Settings > Pages.
  - Paid hosting: upload all of it into the public_html folder.
  Keep the folder names exactly as they are.
